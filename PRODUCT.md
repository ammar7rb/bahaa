# SIGMA Medical Supplies
<!-- impeccable:product-schema 1 -->
## Platform
web
## Product Purpose
An existing medical-supplies storefront and administration application. The current request promotes the approved storefront preview 4 into a complete selectable theme called Sigma Care (theme_sigma_care), alongside Default and Aster.
## Capabilities and Constraints
Confirmed by the user: apply the storefront design only; keep the existing admin panel appearance. Preserve real catalog, product variants, stock, pricing, search/filter/sort, cart, checkout, customer account, addresses, orders, balances, returns, support and policies, respecting existing feature settings and authentication. Include merchant entry and registration; preserve the merchant dashboard. Care is light only and uses existing Flutter user-app icons. Install on the existing VPS without changing the active storefront; authenticated administrators can preview Care in their own browser before activation.
## Brand Commitments
SIGMA name and existing logo. Sigma Care primary #1a428a, cool pale blue backgrounds, white surfaces and dark blue text; Arabic RTL and English LTR. Default and Aster retain their configured brand settings and appearance. Care preserves preview 4's split medical hero, category shortcuts and product shelves.
## Evidence on Hand
Existing storefront https://sigma-eg.net; Laravel/PHP project and real product data. Approved preview 4 is in tools/design-previews. User-app icons originate from E:/project/user-app-main/assets. Care inherits maintained Aster commerce views and bridges current Default account views, with separate homepage configuration and assets. The earlier five isolated demos remain available privately and their admin examples remain simulations.
## Users
Customers browse and purchase medical supplies; merchants enter the existing portal; administrators manage existing store operations and theme selection. The project owner reviews Sigma Care privately before choosing activation. The public active theme remains the owner's existing selection until they change it in theme settings.


## Merchant dashboard redesign — approved 7 October 2026

The user now explicitly authorizes replacing the vendor dashboard shell and page design using the new Sigma Care site system, superseding the earlier dashboard-preservation constraint for this surface. Operate mode; Arabic RTL, light only; one labeled sidebar replacing icon rail plus context panel. Messages and Notifications are standalone header icons with floating previews and View All pages. Support conversations are separate administration-initiated threads for each issue; activation tickets must never appear in this inbox or its badge. Opening a page does not acknowledge a message or accept an order. The user approved adding persisted vendor support threads and an administration management page. Protected order/payment rules remain unchanged.
