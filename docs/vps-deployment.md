# نشر موقع سيجما مباشرة إلى VPS

مصدر كود الموقع هو المجلد `E:\xampp\htdocs\ba`. بعد الانتهاء من مجموعة
تعديلات، افتح PowerShell داخل المجلد وشغّل:

```powershell
.\publish-vps.ps1
```

الأمر يفحص صياغة ملفات PHP المتغيرة، ويحفظ التعديلات في Git المحلي، ثم
يرفعها مباشرة عبر SSH إلى مستودع خاص على الـVPS. يحدث السيرفر ملفات الموقع
ويشغّل Composer وعمليات Laravel اللازمة، ثم يفحص واجهة API. لا يلزم رفع
أي شيء إلى GitHub لإتمام هذا النشر.

يمكن كتابة وصف للتعديل:

```powershell
.\publish-vps.ps1 -Message "وصف التعديل"
```

لا ينقل الأمر قاعدة بيانات XAMPP أو ملفات الوسائط المرفوعة داخل `storage`
ولا يغيّر ملف `.env` أو مفاتيح Passport على السيرفر. إذا فشل الأمر، اقرأ
الرسالة الظاهرة، ولا تفترض أن النشر اكتمل حتى تظهر رسالة نجاح وفحص API.
